# Reference documents

Service manuals and other third-party documents used for the firmware and STM900 work.

PDFs in this folder are **not committed** (`docs/*.pdf` is in `.gitignore`). They are copyrighted by their publishers, and the repository is public. Keep local copies here; the notes taken from them go in `../firmware/FIRMWARE.md` and `../STM900/HARDWARE.md`, which cite them by name and section.

| File | Document | Used for |
|---|---|---|
| `PHILIPS FM93 SERVICE MANUAL.pdf` | Philips FM93 Service Manual | §3.3 central control, §3.5 local control, control-board schematic |
| `FM92E-Modification.pdf` | *Philips FM92E Conversion to 6 Meters*, Rod McCosker VK2DOT, v3.9 (2007) | FM92 board layout, connectors, FM91 schematics (§42), service notes |
